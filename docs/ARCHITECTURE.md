# Architecture Decision Record (ADR)

## 1. Параметры
- **Проект:** Децентрализованная оверлейная сеть на Kademlia DHT.
- **Параметры:** `N=12–15`, `K_BUCKET_SIZE=3`, `ALPHA=3`, `R=3`, `MAX_FRAME_PAYLOAD=65536`.

## 2. Подсистемы

- **Transport & Framing (`internal/protocol`)**:
  - TCP-транспорт. Кастомный 24-байтовый заголовок кадра (`version`, `type`, `flags`, `request_id`, `length`).
  - `StreamDecoder` корректно обрабатывает частичные чтения и склеенные пакеты.
  - Сериализация: MessagePack (меньше и быстрее JSON).

- **Identity (`internal/identity`)**:
  - Ed25519. `NodeID = SHA-256(pubkey)`. 
  - Ключи сохраняются локально в `NODE_STATE_DIR`. При рукопожатии `NodeID` удалённой стороны пересчитывается и проверяется.

- **DHT & Lookup (`internal/dht`)**:
  - XOR-метрика. 256 k-buckets (по 3 контакта). Вытеснение по LRU (перед удалением узла отправляется `PING`).
  - Итеративный Lookup: параллельные запросы к `ALPHA=3` ближайшим узлам для поиска узлов (`FIND_NODE`) и значений (`FIND_VALUE`).

- **RPC & Network (`internal/rpc`)**:
  - Асинхронная обработка. Ответы сопоставляются по `request_id`.
  - Bootstrap-схемы: `star` и `ring`. Периодический `refresh loop` ищет случайные ID для поддержания таблицы.

- **Records & Storage (`internal/records`)**:
  - **Модель:** `NodeRecord` содержит владельца, публичный ключ, адреса, алиас (опционально), версию (`Seq`), время жизни (TTL) и подпись Ed25519.
  - **Каноническое представление:** Для подписи данные склеиваются в строго заданном порядке байт (без использования JSON/MsgPack), что исключает атаки на основе неоднозначности сериализации.
  - **Локальное хранилище:** In-memory `Store` с защитой от отката версий (rollback). Записи с меньшим `Seq` отклоняются. Истекшие по TTL записи не выдаются и удаляются фоновым процессом.
  - **Репликация:** При сохранении запись отправляется на `R=3` ближайших узла. Операция считается успешной при кворуме (2 из 3).
  - **Обслуживание:** Фоновый `maintenanceLoop` очищает истекшие записи и периодически (раз в половину TTL) переопубликовывает записи, принадлежащие текущему узлу.
